Integra SafeMarket en cualquier plataforma

Este demo muestra cómo una empresa (tienda online, fintech, banco) integraría SafeMarket con una sola línea de código. El widget aparece automáticamente y analiza transacciones en tiempo real.

⚡ El panel flotante 🛡️ en la esquina inferior derecha es el widget de SafeMarket funcionando en esta página.
🔍 Widget 1 — Analizador de Transacciones
Ingresa los datos de una transacción y SafeMarket la evalúa en tiempo real
🔔 Widget 3 — Modal de Verificación
Aparece automáticamente cuando una transacción está en REVIEW

Cuando SafeMarket detecta riesgo MEDIUM, en vez de bloquear directamente le pregunta al usuario si confirma la transacción.

⚙️ Cómo integrar en tu plataforma
3 pasos, menos de 5 minutos
1
Incluye el script
Una línea en el HTML de tu plataforma
<!-- Pega esto antes de </body> --> <script src="https://safemarket.co/sdk.js" data-api-key="sm_live_tu_clave" data-position="bottom-right"> </script>
2
Analiza transacciones
Llama al SDK antes de procesar cada pago
const result = await _safemarket.scoreTransaction({ amount: 350000, transaction_type: "PURCHASE", user_id: "uuid-del-usuario", old_balance_orig: 500000, new_balance_orig: 150000, }); if (result.decision === "APPROVE") procesarPago(); if (result.decision === "DECLINE") bloquearPago();
3
Los widgets aparecen solos
El panel flotante y los badges se activan automáticamente
